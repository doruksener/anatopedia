ANATOPEDIA — WINDOWS KURULUMU
=============================

1) Bu klasörü bilgisayarınıza tamamen çıkartın.
2) ANATOPEDIA_BASLAT.bat dosyasına çift tıklayın.
3) Açılan sunucu penceresini uygulamayı kullanırken kapatmayın.
4) Tarayıcı otomatik açılmazsa pencerede yazan yerel adresi Chrome veya Edge'e yapıştırın.

İsteğe bağlı hızlandırma:
ANATOPEDIA_VERI_HAZIRLA.bat seçilmiş açık lisanslı BodyParts3D modellerini
models/stl klasörüne indirir. İndirilen model dosyaları GitHub paketine dahil
değildir.

GÜVENLİK
--------
- Bu depo API anahtarı gerektirmez.
- Hasta verisi, DICOM/NIfTI dosyası veya kimlik belirleyici bilgi eklemeyin.
- Yalnızca kullanım hakkına sahip olduğunuz veri setlerini kullanın.
- Uygulama eğitim amaçlıdır; teşhis veya tedavi amacıyla kullanmayın.
