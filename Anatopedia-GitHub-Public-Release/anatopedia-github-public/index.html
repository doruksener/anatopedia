HOW TO USE

Anatopedia kullanım kılavuzu

01Döndür

Sol tık veya tek parmakla insan modelinin çevresinde dön.

02Yaklaş

Mouse tekeri veya iki parmakla bölgeye yakınlaş.

03Katman ekle

Katman derinliği sürgüsüyle deriden sinire ilerle; sistemler arka planda hazırlanır.

04Yapı seç

Mesh üzerine dokun; sağ panelde kimliği ve geometri bilgisi açılır.

Not: Tüm yüksek çözünürlüklü yapıları aynı anda GPU belleğine koymak tarayıcıyı çökertir. Anatopedia çekirdek atlası arka planda önbelleğe alır; görünür katmanlar GPU’ya, diğerleri hızlı erişim için diske hazırlanır.
