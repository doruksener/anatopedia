# Security policy

Please do not publish suspected vulnerabilities in a public issue.

Before reporting a vulnerability, remove patient data, credentials, access
tokens, local file paths, and any other sensitive information from screenshots
or reproduction files. Repository maintainers should provide a private contact
method in the GitHub Security tab before accepting external reports.

This repository does not require API keys. Do not add credentials directly to
source files; use local environment variables and keep them out of version
control.
